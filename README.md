Projet Gestion des tâches

Description

Ce projet est une application Python qui permet de gérer une liste de tâches.

Fonctionnalités

- Ajouter une tâche.
- Afficher les tâches.
- Rechercher une tâche.
- Quitter le programme.

Technologies utilisées

- Python
- Visual Studio Code

Exécution

Lancer le fichier main.py pour exécuter le programme.
